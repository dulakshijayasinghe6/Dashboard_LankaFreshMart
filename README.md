## Project Overview

This project is a responsive sales dashboard developed for Lanka Fresh Mart. It displays monthly revenue, total units sold, the best-performing month, and the branch with the highest Q2 revenue. The dashboard also includes two charts to present sales information clearly.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Google Fonts

## Layout and Features

**CSS Grid:** Used to arrange the four summary cards and two charts. Media queries adjust the layout for desktop, tablet, and mobile screens.

**Flexbox:** Used in the navigation bar, KPI cards, and chart headings to align elements properly.

**JavaScript:** Used to calculate KPI values, display charts, control the mobile menu, and switch between light and dark modes.

## How to Run

Open the `index.html` file using Google Chrome or Firefox. An internet connection is required to load Chart.js and Google Fonts.

## Known Issues

The dashboard requires an internet connection to display the charts. The navigation links work within the same page because this is a single-page prototype.
